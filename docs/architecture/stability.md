# 技能生态稳定性协议（Stability Protocol·V0.3.0）

> 来源: 2026-08-08 黑盒外挂治理分析（技能生态缺口4项）+ "top-tier commercial delivery standard"
> 配套: router_rules.json（混淆词对）· pruner.py（回滚快照）· 校准协议

## 一、混淆词对库（防路由幻觉·R3强化）

- 数据: `src/data/confusion_pairs.json`（10对·机器可读）
- 使用: 用户语命中词对任一方 → 进入混淆裁决（R3）·按深度锚点判定·禁表面词直判
- 维护: 映射表新增易混淆邻居 → 同步入库（周盘点核对）

## 二、修剪回滚快照（防误伤·可逆）

```
1. 快照: 修剪前全量SKILL.md+references复制到 archives/skills/snapshots/<name>-<date>/
2. 声明: 修剪记录入router_log（时间/双信号数据/快照路径）
3. 回滚: 归档态恢复=快照复制回技能库+router_log追加恢复记录
4. 判据: 修剪后2周内路由质量下降（盲测<修剪前）→ 自动回滚
```

## 三、阈值校准协议（拒绝魔法数）

- 全参数可校准（触发θ_t/边权重θ_e/K_max/共识θ_c/独立性θ_i/锚点α/桥β/学习率η）
- Trigger: router_log ≥30 entries or covering ≥10 anchors → first calibration
- 纪律: 参数调整必附数据依据·调整记录入router_log·可回滚

## 四、SoT式注入（预演-修剪-注入·Harness化）

```
①谁预演: 复杂任务前低token小调用跑divergent preplay reasoning（anchor-point trigger→子图激活→Top-K）
②怎么剪: 8-axiom filter+只留"影响决策的约束+事实快照"（架构约束不得摘要）
③注入哪里: 前缀尾部（静态锚定）或状态栏（注意力最高）·SoT两步法: 先骨架后执行
④怎么验证: 注入前后A/B（确定性检查）·差异不可观测→撤回注入
```

## 五、稳定性判据

```
1. 路由幻觉率: 盲测正确率≥7/7（每轮整合后回归）
2. 修剪误伤: 回滚率≤20%（修剪后2周）
3. 校准执行: 首校触发后2周内完成·调整必附数据
4. 注入验证: SoT A/B差异可观测率=100%
```

## 算法规格（Algorithm Spec·稳定性参数可执行定义）

### 校准参数表（全部可校准·拒绝魔法数）

| 参数 | 含义 | 初始值 | 校准周期 | 数据源 |
|:---|:---|:---|:---|:---|
| θ_t | 触发阈值 | 0.5 | 2周 | 触发-贡献对照 |
| θ_e | 关联边权重阈值 | 0.3 | 2周 | 激活子图贡献 |
| K_max | 最大发散请求数 | 5（复杂7·简单3） | 2周 | K+1增益<5%封顶 |
| θ_c | 共识聚类阈值 | 0.7 | 4周 | 共识-人工一致率 |
| θ_i | 独立性阈值 | 0.4 | 4周 | 伪并行检出率 |
| α/β | 锚点/桥权重 | 0.7/0.3 | 4周 | 命中贡献对比 |
| η | 网络学习率 | 0.1 | 8周 | 权重预测准确率 |

### SoT注入四步（预演-修剪-注入-验证）

```
① 预演: 复杂任务前低token小调用跑发散推演（触发θ_t→子图激活θ_e→Top-K截断）
② 修剪: 8公理过滤 + 只留"影响决策的约束+事实快照"（架构约束不得摘要·AC-004）
③ 注入: 前缀尾部（静态锚定·缓存友好）或状态栏（注意力最高）·SoT两步: 先骨架后执行
④ 验证: 注入前后A/B（确定性检查）·差异不可观测→撤回注入
```
